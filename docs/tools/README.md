# wave.py - осциллограммы в SVG

`wave.py` рисует цифровые временные диаграммы в стиле WaveDrom и выдаёт
готовый inline SVG для статических HTML-страниц (JavaScript при просмотре не нужен).
Только стандартная библиотека Python 3.12.

## Использование

```
python wave.py demo_wave.json > out.svg     # из JSON-файла
python wave.py --demo > demo.svg            # встроенный пример
```

Из Python:

```python
from wave import render, render_file
svg = render(spec, cell_width=20, row_height=30, font="monospace")
svg = render_file("demo_wave.json")
```

SVG можно вставлять прямо в HTML. Цвета задаются CSS-переменными с запасными
значениями, фон прозрачный, поэтому диаграмма работает в светлой и тёмной теме:
`--wave-fg` (линии и текст), `--wave-grid`, `--wave-x` (штриховка x),
`--wave-edge` (стрелки), `--wave-bg` (подложка под подписями стрелок).

## Формат

```json
{
  "signal": [
    {"name": "clk",  "wave": "p........"},
    ["Группа", {"name": "d", "wave": "x.3.4.x..", "data": ["A", "B"]}],
    {},
    {"name": "v", "wave": "0.1..|.0.", "node": "..a"}
  ],
  "head": {"text": "Заголовок", "tick": 0},
  "foot": {"text": "Подпись"},
  "config": {"hscale": 1},
  "edge": ["a~>b подпись"]
}
```

Символы `wave`:

| Символ | Значение |
|--------|----------|
| `p` `n` | тактовый сигнал (положительный / отрицательный) |
| `P` `N` | то же со стрелкой на фронте |
| `0` `1` | низкий / высокий уровень |
| `x` | не определено (штриховка) |
| `z` | высокоимпедансное состояние (средний уровень) |
| `=` | шина (серая), подпись берётся из `data` |
| `2`..`9` | шина с пастельной заливкой другого цвета |
| `.` | продолжить предыдущее состояние |
| `\|` | разрыв (обрыв временной оси) |

- `data` - список строк или строка через пробел; подписи идут по порядку к шинам `=` и `2..9`.
  `null` или `""` в списке оставляет соответствующий сегмент без подписи. Если подпись не помещается
  в сегмент даже мелким шрифтом (9px), она не рисуется - увеличьте `config.cell_width`.
- `config.cell_width` - ширина такта в пикселях (перекрывает значение по умолчанию из `render()`).
- Вложенный список `["Имя", {...}, {...}]` - группа со скобкой слева (группы можно вкладывать).
- `{}` - пустой отступ между сигналами.
- `head.tick` - нумерация тактов, начиная с заданного числа.
- `node` - строка с метками узлов (буква на позиции такта); `edge` - стрелки между узлами:
  `->`, `~>` (кривая), `-|>`, `|->`, `-|->` (ломаные), `<->` (двусторонняя); после стрелки идёт подпись.
