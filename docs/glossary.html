Глоссарий

Термины PCIe, NVMe и нашего проекта в одном месте. В скобках — английский оригинал, как он встречается в спецификациях и документации Xilinx.

PCI Express

Таблица Г.1. Термины PCIe
ТерминЗначение
Root Complex (RC)Корневой узел иерархии PCIe, представляющий сторону процессора/памяти. В нашем проекте — FPGA.
Root Port (RP)Порт Root Complex, к которому подключён линк. Имеет собственное конфигурационное пространство типа 1 (мост).
Endpoint (EP)Оконечное устройство (SSD). Имеет конфигурационное пространство типа 0.
Lane, LinkLane — одна дифференциальная пара на приём и одна на передачу. Link — набор lane'ов (x1, x4, x8…) между двумя портами.
Gen1 / Gen2 / Gen3Поколения скорости: 2,5 / 5 / 8 GT/s на lane. Kintex-7 поддерживает Gen1 и Gen2.
GT/s (гигатрансфер в секунду)Символов в секунду на линии. Из-за кодирования 8b/10b в Gen1/Gen2 полезных бит на 20 % меньше.
LTSSMLink Training and Status State Machine — автомат обучения линка (Detect → Polling → Configuration → L0, Recovery).
L0Рабочее состояние линка. В pcie_7x: pl_ltssm_state = 0x16.
PERST#Fundamental reset — сигнал сброса, который Root Complex подаёт устройству. У нас его формирует FPGA.
REFCLKОпорный тактовый сигнал 100 МГц. В нашей схеме общий для FPGA и SSD (common clock).
TLPTransaction Layer Packet — пакет уровня транзакций: заголовок 3 или 4 DW + необязательные данные.
DLLPData Link Layer Packet — служебный пакет канального уровня (ACK/NAK, кредиты потока). Внутри блока pcie_7x, пользователю не виден.
DW (dword)Двойное слово, 4 байта. Единица длины TLP (поле Length) и выравнивания адресов.
MRd / MWrMemory Read / Memory Write — запрос чтения/записи памяти. 32 — заголовок 3 DW (адрес < 4 ГБ), 64 — 4 DW.
CfgRd0 / CfgWr0Configuration Read/Write Type 0 — доступ к конфигурационному пространству устройства непосредственно за портом.
Cpl / CplDCompletion (без данных) / Completion with Data — ответ на непосланный (non-posted) запрос.
Posted / Non-postedPosted (MWr, Msg) — не требует ответа. Non-posted (MRd, Cfg) — требует Completion.
Requester / CompleterТот, кто послал запрос / тот, кто отвечает. При записи на SSD накопитель — requester, FPGA — completer.
Requester ID, Completer ID16-битные идентификаторы Bus:Device.Function отправителя запроса и ответчика.
TagНомер запроса (5 или 8 бит), по которому requester сопоставляет completion с запросом.
Byte Count (BC)В CplD: сколько байт осталось передать, включая этот пакет. 0 означает 4096.
Lower Address (LA)В CplD: младшие 7 бит адреса первого байта данных этого пакета.
MPSMax Payload Size — максимальный размер данных в одном TLP (128/256/512… байт). Программируется в Device Control у обеих сторон.
MRRSMax Read Request Size — максимальный размер одного запроса чтения.
RCBRead Completion Boundary — граница (64 или 128 Б), по которой разрешено дробить ответ на чтение.
BARBase Address Register — регистр, через который хост назначает устройству окно адресов. У NVMe BAR0 содержит регистры контроллера.
BDFBus:Device.Function — адрес устройства в конфигурационном пространстве. SSD у нас 01:00.0.
EnumerationПеречисление: обход конфигурационного пространства, назначение номеров шин и адресов BAR.
BME, MSEBus Master Enable, Memory Space Enable — биты регистра Command. Без BME устройство не может само обращаться к памяти хоста.
CRSConfiguration Request Retry Status — ответ «я ещё не готов», допустимый до 1 с после сброса.
UR / CAUnsupported Request / Completer Abort — статусы ошибок в Completion.
Flow control creditsКредиты потока: приёмник заранее сообщает, сколько заголовков/данных он может принять. Управляются блоком pcie_7x.
StraddlingВ 128-битном режиме pcie_7x: окончание одного TLP и начало следующего в одном такте шины.
cfg_mgmtПорт блока pcie_7x для доступа к собственному конфигурационному пространству Root Port.

NVMe

Таблица Г.2. Термины NVMe
ТерминЗначение
Controller (контроллер)Логика накопителя, выполняющая команды NVMe. Регистры контроллера находятся в BAR0.
Namespace (NSID)Логический том на накопителе. Мы используем NSID = 1.
LBALogical Block Address — номер логического блока (512 или 4096 Б, поле LBADS).
SQ / CQSubmission Queue / Completion Queue — кольцевые очереди команд (64 Б записи) и завершений (16 Б записи) в памяти хоста.
SQE / CQESubmission/Completion Queue Entry — одна запись соответствующей очереди.
Admin queue, I/O queueОчереди с QID 0 (административные команды) и QID ≥ 1 (команды ввода-вывода).
DoorbellРегистр в BAR0, в который хост пишет новое значение tail (SQ) или head (CQ).
Head / TailУказатели кольцевой очереди: производитель двигает tail, потребитель — head.
Phase Tag (P)Бит в CQE, инвертируемый при каждом обороте очереди; позволяет хосту отличить новые записи от старых без счётчика.
CIDCommand Identifier — номер команды, уникальный среди незавершённых команд очереди.
PRPPhysical Region Page — указатель на страницу памяти с данными. PRP1, PRP2 и список PRP описывают буфер команды.
PRP listМассив 8-байтовых PRP-указателей на одной странице памяти; используется для переносов больше двух страниц.
MPS (NVMe)Memory Page Size в регистре CC — размер страницы хоста (у нас 4 КиБ). Не путать с MPS PCIe.
CAP, CC, CSTSCapabilities, Configuration, Status — главные регистры контроллера.
AQA, ASQ, ACQРазмеры и базовые адреса административных очередей.
IdentifyКоманда, возвращающая 4 КиБ описания контроллера (CNS=1) или namespace (CNS=0).
MDTSMaximum Data Transfer Size — максимальный размер одной команды, в степенях двойки от размера страницы.
FlushКоманда, сбрасывающая энергозависимый кэш записи на носитель.
Shutdown (SHN/SHST)Процедура штатного выключения контроллера перед снятием питания.
SLC-кэшОбласть TLC/QLC-памяти, временно работающая в однобитном режиме для быстрой записи; после её заполнения скорость падает.
GCGarbage collection — фоновая перезапись блоков NAND, вызывающая всплески латентности.
HMBHost Memory Buffer — память хоста, которую запрашивают накопители без DRAM. Мы её не предоставляем.

Термины проекта

Таблица Г.3. Внутренние понятия
ТерминЗначение
tlp_axisВнутренний формат потока TLP: 128 бит, заголовок в первом такте, данные с второго такта, байты в порядке памяти (глава 4).
Слот (slot)Участок кольца данных размером в одну команду (128 КиБ). Номер слота равен CID команды.
Кольцо данных (data ring)BRAM-буфер из N слотов, куда поступает входной поток и откуда SSD читает данные.
Синтез PRPВычисление содержимого списка PRP «на лету» из адреса запроса вместо хранения в памяти.
SequencerВерхний автомат запуска: линк → перечисление → настройка RP → инициализация NVMe → работа → останов.
