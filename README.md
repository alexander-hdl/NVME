# NVMe-хост на «голой» Kintex-7

Аппаратный (без процессора) NVMe-хост для Xilinx Kintex-7: FPGA выступает в роли PCIe Root Complex,
сама поднимает линк PCIe Gen2 x4, перечисляет M.2 NVMe SSD, инициализирует контроллер NVMe и пишет на него
непрерывный поток данных последовательной записью на предельной для линка скорости (расчётно 1,6–1,8 ГБ/с).

Проект одновременно является учебной лабораторной работой: вся архитектура, интерфейсы модулей,
временные диаграммы и основы PCIe/NVMe «с нуля» описаны в `docs/` (откройте `docs/index.html`).

| Что | Статус |

## Быстрый старт (симуляция)

Требуется Vivado 2022.2 (xsim) и Python 3.

```bash
bash sim/scripts/run_xsim.sh            # все тесты
bash sim/scripts/run_xsim.sh models top # самопроверка моделей и системный тест
```

Системный тест `tb_top`: линк → перечисление → инициализация NVMe → поток 1 МиБ → останов → shutdown;
данные сверяются по LBA с эталоном, печатается доля занятых тактов шины TX.

## Ключевые решения

- Сырой TLP-интерфейс pcie_7x (а не AXI-мост): completer отвечает на MRd накопителя из BRAM без «пузырей».
- Внутренний чистый формат потока TLP; все особенности 7-series (straddling, выравнивание 3DW, big-endian DW) изолированы в двух адаптерах.
- Память хоста — BRAM: кольцо 8 × 128 КиБ, очереди SQ/CQ, буфер Identify; списки PRP синтезируются арифметически.
- Опрос CQ по фазовому биту, прерывания не используются; штатный shutdown перед выключением.

Подробности и обоснования — `ARCHITECTURE.md` и глава 3 учебника.
