# NVMe-хост на «голой» Kintex-7

Аппаратный (без процессора) NVMe-хост для Xilinx Kintex-7: FPGA выступает в роли
PCIe Root Complex, инициализирует M.2 NVMe SSD и записывает на него непрерывный
поток данных последовательной записью на предельной для PCIe Gen2 x4 скорости.

Проект одновременно является учебной лабораторной работой: вся архитектура,
интерфейсы модулей и временные диаграммы описаны в `docs/`.

Структура:

| Каталог | Содержимое |
|---|---|
| `docs/` | Учебное пособие (HTML): PCIe и NVMe с нуля, архитектура, интерфейсы, осциллограммы |
| `rtl/pcie/` | Слой PCIe: TLP RX/TX, конфигуратор (enumeration), completer |
| `rtl/nvme/` | Слой NVMe: инициализация контроллера, очереди, генератор команд записи |
| `rtl/common/` | Общие примитивы (FIFO, кольцевые буферы, CDC) |
| `sim/` | Тестовое окружение: поведенческая модель NVMe SSD и PCIe-блока, тесты для xsim |
| `fpga/` | Проект Vivado, констрейны, скрипты генерации IP |
| `research/` | Отчёты исследования открытых решений и спецификаций |
